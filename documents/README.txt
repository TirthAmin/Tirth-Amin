Put your downloadable files in THIS folder (documents/).
Then list each one in assets/documents.js so it appears on documents.html.
Every file here is offered behind the confidentiality-agreement gate.

NOTE: On plain static hosting, files in this folder are technically reachable
by their direct URL. The signature gate creates the signed, logged record and
deters casual access. To HARD-restrict files, deliver them through a small
server step (e.g., a serverless function that emails the file after signing,
or a data-room service). See DEPLOY.md.
